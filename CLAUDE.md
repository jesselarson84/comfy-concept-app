# Working on this project

## Batches of changes

When I start a "new batch" of changes (or send items as "first one", "next", and so on), only collect them:

- Confirm each item in a line or two and ask about anything unclear. Don't repeat the whole list in each reply; show it only when I ask for it or before building.
- Do not edit any files until I say the batch is done (for example "that's all", "go", or "do the batch").
- Then build the whole batch together.
